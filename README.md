# Questudy

사용자가 올린 학습 자료로 문제를 생성하고, 문제 풀이를 전투와 지도 탐험으로 연결하는 로컬 웹 기반 학습 서비스.

## 목표와 현재 단계

완성 목표는 여러 자료를 자료별 학습 영역으로 구성하고, 중앙에서 원하는 영역을 선택하여 탐험하는 경험이다. 첫 구현은 PDF 한 개로 문제 생성부터 전투 노드 하나와 결과 확인까지 연결한다. 현재는 Python + FastAPI 실행 환경과 Swagger UI에서 호출할 샘플 API를 준비한 단계다.

## 팀

| 역할 | 담당 | 책임 |
| --- | --- | --- |
| PM | 유민서 | 기획·일정·이슈·품질 관리, 필요시 백엔드 구현 |
| UX·프론트엔드 | 백승빈, 손시은 | 게임·학습 경험, UI/UX 설계와 화면 구현 |
| System·백엔드 | 김수연, 최지은 | 게임 규칙, 자료 처리·AI, 저장과 시스템 통합 |

백엔드는 테스트 스켈레톤 페이지에서 기능을 검증하고, 프론트는 제출용 화면을 만들며 검증된 기능부터 연결한다. 요청·응답 예시로 병행 작업을 시작하며, 검증과 인계 기준은 [개발 참여 기준](CONTRIBUTING.md#연결-합의와-구현)을 따른다.

## 백엔드 개발용 실행

Python 3.12와 [uv](https://docs.astral.sh/uv/getting-started/installation/)를 사용한다. `.python-version`에 Python 버전, `pyproject.toml`에 직접 의존성, `uv.lock`에 설치 버전을 기록한다.

Windows에서는 루트의 `dev-backend.bat`를 더블클릭한다.

터미널에서는 저장소 루트에서 다음과 같이 실행한다.

```sh
uv run --locked python -m backend
```

브라우저 자동 열기가 실패하면 [Swagger UI](http://127.0.0.1:8000/docs)를 직접 연다. `uv`를 찾지 못하면 설치 후 터미널 또는 실행 파일을 다시 연다. 실행 파일은 실패 메시지를 읽을 수 있도록 창을 유지한다.

주소·포트 변경이나 자동 재시작이 필요한 개발 작업은 아래 명령을 사용한다.

```sh
uv sync --locked
uv run --locked uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

첫 명령은 프로젝트 전용 `.venv`와 테스트 의존성을 준비한다. 이 방식은 서버 실행 후 Swagger UI를 직접 연다. 루트 주소도 Swagger UI로 이동한다.

포트 사용 중 오류가 나오면 `--port 8001`처럼 변경하고 브라우저 주소도 맞춘다. 기존 프로세스는 해당 프로세스의 사용자가 종료한다. 개발 중 자동 재시작이 필요하면 실행 명령 끝에 `--reload`를 추가한다.

샘플 API는 API 키나 환경변수 없이 실행한다. 실행 주소와 포트는 위 명령으로 지정한다. 비밀값은 서버 환경변수 또는 Git에서 제외된 루트 `.env`에서 관리하며, 현재 명령은 `.env`를 자동으로 읽지 않는다. 프론트 코드·응답·로그에 비밀값을 넣지 않는다.

Swagger UI의 기본 JS·CSS는 외부 CDN에서 불러오므로 화면 로딩에 인터넷 연결이 필요하다. API 요청은 로컬 백엔드로 전달된다.

## 프론트엔드 탐험 지도 미리보기

Node.js 22 이상에서 루트의 `dev-frontend.bat`를 실행하거나, `frontend` 폴더에서 `npm run dev`를 실행한다. <http://127.0.0.1:5173>에서 확인한다. 별도 npm 의존성 설치는 필요하지 않다.

중앙 출발·지도 이동·미니맵·난이도 선택·단계별 구름 해제를 목 데이터로 확인하는 화면이다. 실제 PDF·전투·저장 API는 아직 연결하지 않았으며 새로고침하면 초기화된다. 실행과 조작, API 교체 경계는 [프론트엔드 안내](frontend/README.md)를 따른다.

## API 확인

| 요청 | 결과 |
| --- | --- |
| `GET /api/health` | `200`, `{"status":"ok"}` |
| `POST /api/sample` | 문자열 검증 후 `200`, 앞뒤 공백을 제거한 메시지 반환 |
| `GET /openapi.json` | 요청·응답 규격 |

Swagger UI에서 `POST /api/sample` → `Try it out` → 본문 입력 → `Execute` 순서로 호출한다.

```json
{"message": "안녕하세요"}
```

위 요청은 동일한 메시지를 반환한다. 메시지는 앞뒤 공백을 제외한 1~200자 문자열이다. 빈 문자열·공백만 있는 값·필드 누락·문자열 외 타입·길이 초과·잘못된 JSON은 `422`와 FastAPI 기본 `detail` 오류 목록을 반환한다. 상태 코드와 오류의 `loc`, `type`, `msg`로 실패를 확인한다.

프론트도 같은 HTTP API를 호출한다. 프론트 개발 서버를 별도 포트로 띄울 때는 팀이 정한 개발 프록시 또는 명시적인 CORS 허용 주소를 설정한다. 현재 백엔드는 같은 출처의 Swagger UI에서 검증한다.

## 검사와 기능 추가

```sh
uv run --locked python -m pytest
```

테스트는 정상 입력·입력 오류·JSON 오류·상태 API·문서 경로를 확인한다. 엔드포인트와 요청·응답 모델은 `backend/main.py`, 관련 테스트는 `backend/tests/`에 추가한다. 모델과 경로를 추가하면 Swagger UI에도 반영된다. 실제 PDF 처리·AI 생성·게임 규칙은 해당 후속 이슈에서 구현한다.

## 디렉터리

```text
frontend/           화면·사용자 입력·결과 표시
backend/            FastAPI 앱·요청/응답 모델·백엔드 테스트
scripts/            공통 실행·개발 보조 작업
tests/integration/  연결된 사용자 흐름 검증
tests/fixtures/     공유 가능한 테스트 자료
docs/               기능 명세·개발 계획
.local/             로컬 실행 데이터 (Git 제외)
```

단위 테스트는 해당 구현 가까이에 둔다. `.local/`에는 업로드 자료·생성 결과·진행 기록·로그를 보관한다. 공유 테스트 자료는 사용·공유 권한과 개인정보 포함 여부를 확인한다. 루트 `.env` 계열은 Git에서 제외하며, 비밀값 없는 `.env.example`은 공유할 수 있다.
