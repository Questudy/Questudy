# Questudy

사용자가 올린 학습 자료로 문제를 생성하고, 문제 풀이를 전투와 지도 탐험으로 연결하는 로컬 웹 기반 학습 서비스.

## 목표와 현재 단계

완성 목표는 여러 자료를 자료별 학습 영역으로 구성하고, 중앙에서 원하는 영역을 선택하여 탐험하는 경험이다. 첫 구현은 PDF 한 개로 문제 생성부터 전투 노드 하나와 결과 확인까지 연결한다. 현재는 기획과 개발 구조를 준비한 단계이며 제품 실행 코드는 아직 없다.

## 팀

| 역할 | 담당 | 책임 |
| --- | --- | --- |
| PM | 유민서 | 기획·일정·이슈·품질 관리, 필요시 백엔드 구현 |
| UX·프론트엔드 | 백승빈, 손시은 | 게임·학습 경험, UI/UX 설계와 화면 구현 |
| System·백엔드 | 김수연, 최지은 | 게임 규칙, 자료 처리·AI, 저장과 시스템 통합 |

백엔드는 테스트 스켈레톤 페이지에서 기능을 검증하고, 프론트는 제출용 화면을 만들며 검증된 기능부터 연결한다. 요청·응답 예시로 병행 작업을 시작하며, 검증과 인계 기준은 [개발 참여 기준](CONTRIBUTING.md#연결-합의와-구현)을 따른다.

## 실행

목표는 **루트에서 한 번 실행하면 필요한 프로세스가 준비된 후 브라우저가 열리는 것**이다. 실행 진입점은 아직 구현되지 않았다.

시작에 실패하면 원인과 재시도 방법을 안내한다. 종료 시 해당 실행이 시작한 프로세스만 함께 정리한다.

## 디렉터리

```text
frontend/           화면·사용자 입력·결과 표시
backend/            게임·학습 처리, AI, 저장·통합
scripts/            공통 실행·개발 보조 작업
tests/integration/  연결된 사용자 흐름 검증
tests/fixtures/     공유 가능한 테스트 자료
docs/               기능 명세·개발 계획
.local/             로컬 실행 데이터 (Git 제외)
```

단위 테스트는 해당 구현 가까이에 둔다. `.local/`에는 업로드 자료·생성 결과·진행 기록·로그를 보관한다. 공유 테스트 자료는 사용·공유 권한과 개인정보 포함 여부를 확인한다. 루트 `.env` 계열은 Git에서 제외하며, 비밀값 없는 `.env.example`은 공유할 수 있다.
