# 퀘스터디 · Questudy

이 저장소의 프론트 작업 기준 경로는 `questudy-frontend/questudy/`입니다. 협업·브랜치·검증은 루트의 [개발 참여 기준](../../CONTRIBUTING.md), 제품 정책은 [기능 명세](../../docs/functional-spec.md)를 따릅니다. 아래 사용 흐름은 현재 로컬 구현 설명이며 제품 정책의 확정이나 백엔드 연결 완료를 뜻하지 않습니다. 차이가 있으면 팀과 확인하고, 준비된 백엔드 기능부터 연결합니다.

최근 Figma 반영: 서비스 소개(`#about`), 문의하기(`#contact`)를 추가했습니다. 기존 이용안내와 개인정보처리방침은 `#guide`, `#privacy` 주소에서 계속 볼 수 있습니다.

사용자 UI 원칙: Figma에 홈 메뉴가 있어도 헤더에 별도의 홈 버튼을 추가하지 않습니다. 홈 이동은 로고 링크를 사용합니다.

문의 전송은 아직 연결되지 않았습니다. 현재는 접수 준비 안내와 내용 복사를 제공하며, 실제 접수 완료로 표시하지 않습니다. 운영 API가 준비되면 `web/contact.ts`의 `CONTACT_ENDPOINT`를 설정하세요. API는 `{ email, message }` JSON을 받으며 성공 시 HTTP 2xx를 반환해야 합니다. 실패 시 입력을 유지하고 재시도를 안내합니다. 문의 초안은 현재 탭의 메모리에만 유지합니다.

화면 진입, 카드 등장, 버튼 반응, 팝업, 진행률, 업로드, 문제 피드백에 모션을 적용했습니다. 기기의 동작 줄이기 설정에서는 모션과 홈 SVG 인트로를 끕니다. 모션 구현은 `web/motion.ts`와 `web/style.css`에 있습니다.

Figma의 최종 색종이 시안을 바탕으로 구현한 로컬 학습 게임입니다.

## 실행 방법

1. 저장소 루트에서 `questudy-frontend/questudy` 폴더로 이동합니다.
2. Node.js와 Python 3이 필요합니다. 최초 실행 시 `npm ci`, 코드 변경 후에는 `npm run build`를 실행한 뒤 아래 서버를 시작합니다. Windows PowerShell에서는 `npm.cmd`를 사용할 수 있습니다.

   Windows
   ```powershell
   py -m http.server 8001 --bind 127.0.0.1 --directory web
   ```

   macOS / Linux
   ```bash
   python3 -m http.server 8001 --bind 127.0.0.1 --directory web
   ```

3. 브라우저에서 [http://127.0.0.1:8001](http://127.0.0.1:8001)을 엽니다. 백엔드 기본 포트 `8000`과 구분합니다. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

## 사용 흐름

- **내 지도**에서 예시 지도를 열거나, **지도 만들기**에서 PDF를 추가해 새 지도를 만듭니다.
- 지도 제목과 문제 수(10~30)를 입력합니다. 고급 설정의 쪽수는 PDF 뷰어의 쪽 번호 기준이며 `1-5, 8` 형식을 사용합니다.
- 시작 노드에서 난이도를 선택하고 인접한 노드로 이동합니다. 오답 시 하트가 줄고, 정답으로 몬스터를 쓰러뜨립니다. 회복 물약과 PASS를 사용할 수 있습니다.
- 전투 후 보상을 고릅니다. 전투를 모두 마치면 100% 결과 화면이 열립니다. 중간에 종료하면 아카이브에서 결과와 다시 볼 문제를 확인할 수 있습니다.
- 지도 이름·아이콘·즐겨찾기와 진행 기록은 같은 브라우저의 로컬 저장소에 남습니다. 예시 지도는 플레이 흐름을 보여 주기 위한 DB 문제로 구성했습니다.

## 구현 범위

- HTML, CSS, TypeScript ES 모듈 기반입니다. `npm run build`로 브라우저용 JavaScript를 `web/dist/`에 생성합니다. `npm run typecheck`로 타입을 검사하고, 개발 중에는 별도 터미널에서 `npm run dev`로 자동 컴파일할 수 있습니다. 외부 PDF.js 배포본은 `web/vendor/`에 유지합니다.
- PDF.js로 텍스트를 읽은 뒤 규칙 기반으로 빈칸 객관식 문제를 일괄 구성합니다. 생성형 AI API, OCR, 계정 및 서버 동기화는 구현 범위에서 제외했습니다. 스캔 이미지로만 이루어진 PDF는 텍스트 추출이 필요합니다.
- 업로드한 원본 PDF는 서버로 전송하지 않습니다. 생성된 문제, 원문 발췌와 풀이 이력은 브라우저에 저장합니다.
- 게임 내 지도와 전투 화면은 시스템 흐름 및 기능 명세를 바탕으로 색종이 스타일에 맞춰 구성했습니다.
- Figma 원본 로고, 장식, 버튼 및 아이콘을 `web/assets/`에 둡니다. 서드파티 PDF 파서 라이선스는 `web/vendor/PDFJS-LICENSE`에 있습니다.

## 주요 파일

| 파일 | 역할 |

| `web/index.html` | 공통 헤더와 웹 앱 진입점 |

| `web/app.ts` | 화면 이동, 화면 렌더링, 이벤트와 저장 |
| `web/game.ts` | 탐험 지도, 노드 조건, 학습 기록 |
| `web/questions.ts` | PDF 텍스트 읽기, 출제 범위, 문제 생성 |
