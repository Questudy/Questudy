# 프론트엔드 작업 지침

- 프론트 구현과 자료 업데이트는 `questudy/`를 기준으로 한다. 소스는 `questudy/web/`, 실행·검사 명령은 `questudy/package.json`과 `questudy/README.md`에서 확인한다.
- 루트 `AGENTS.md`와 `CONTRIBUTING.md`를 함께 따른다. 제품 정책의 기준은 루트 `docs/functional-spec.md`다. 로컬 구현과 명세가 충돌하면 차이와 영향을 밝히고 제품 정책을 임의로 확정하지 않는다.
- 프론트 README의 UI 원칙을 지킨다. 홈 이동은 로고를 사용하고, 문의 API 연결 전에는 실제 접수 완료로 표시하지 않는다. 동작 줄이기 설정을 존중한다.
- 현재 문제 생성·게임 판정·브라우저 저장은 로컬 구현이다. 백엔드 연결 시 요청·응답·실패 처리를 먼저 합의하고, 스켈레톤에서 검증된 동일 기능을 호출한다. 판정과 상태의 원본을 화면에 중복 구현하지 않는다.
- 문서는 링크·용어·규칙의 일치를 확인하고, 소스 변경 시 타입 검사와 빌드를 수행한다. 화면 변경은 실제 렌더링과 조작으로 검증하며, 샘플 확인과 실제 백엔드 연결 검증을 구분해 보고한다.
