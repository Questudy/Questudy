# Questudy 기능 명세

> 2026-11-02 합의 반영. 완성 목표와 첫 구현 범위를 구분하며, 채택한 규칙은 구현·검증 완료를 뜻하지 않는다. 재논의 사항과 미정 값은 5~7절에서 관리한다.

## 1. 서비스 개요

퀘스터디(Questudy)는 Quest와 Study를 결합한 **AI 기반 게임형 학습 서비스**다. 사용자가 올린 복수의 학습 자료를 생성형 AI가 분석하여 학습 문제와 자료별 영역을 가진 탐험 지도를 생성한다.

문제 풀이를 간단한 턴제 RPG 전투로, 학습 진척을 맵 탐험과 확장으로 표현한다. 자료를 읽는 데 그치지 않고 문제를 해결하면서 학습 동기와 몰입도를 높이는 것이 목표다.

### 완성 목표와 첫 구현 범위

- **완성 목표:** 여러 학습 자료를 하나의 지도에 구성한다. 영역은 주제가 아니라 업로드한 자료별로 나누며, 같은 주제의 자료도 각각 별도 영역을 갖는다. 컴퓨터구조와 요리처럼 다른 주제를 함께 학습할 수 있다.
- **첫 구현:** 텍스트 PDF 한 개, 단일 난이도 구간, 전투 노드 하나로 업로드부터 결과 확인까지 검증한다. 이후 탐험·보상 반복과 저장·이어하기를 연결하고 복수 자료·자료별 영역으로 확장한다.
- 과거의 AI 챕터 분류·챕터 목록 확인·`[챕터 구분 없음]` 선택은 현재 자료별 영역 구성의 필수 단계가 아니다. 기존 티켓의 ‘챕터 구분 없음’은 첫 구현에서 자료 내부를 챕터로 나누지 않는 범위를 뜻한다.

### 용어

| 용어 | 의미 |
| --- | --- |
| 자료 영역 | 중앙에서 한 방향으로 펼쳐지며 업로드한 자료 하나를 학습하는 노드 묶음 |
| 난이도 결정 노드 | 다음 결정 노드 전까지 적용할 난이도를 선택하는 비전투 노드. 화면 이름은 미정 |
| 난이도 구간 | 하나의 난이도 결정 노드에서 선택한 난이도가 유지되는 범위 |
| 나가기 | HP·인벤토리·진행 상태를 저장하고 일시 중단하는 행위 |
| 탐험 종료 | 사용자가 결과를 확정하고 지도를 아카이빙하는 행위 |
| 지도 완료 | 전체 전투 노드를 모두 클리어한 상태 |
| 아카이빙된 지도 | 플레이가 종료되어 별도 메뉴에 보관된 지도. 재플레이 방식은 미정 |
| PASS | 문제를 건너뛰어 해당 적을 제거하는 아이템 효과. 정답과 구분하여 기록 |
| 문제 오류 제외 | 오류로 판단한 문제의 적을 제거하는 처리. 정답·PASS와 구분하여 기록 |

## 2. 핵심 사용자 흐름

1. 학습할 자료들을 업로드한다.
2. 자료별 문제와 지도 구성을 준비하고, 전체 문제 준비가 끝난 뒤 지도에 입장한다.
3. 중앙 출발점에서 원하는 자료 영역을 선택하고, 입구의 난이도 결정 노드에서 상·중·하를 선택한다.
4. 공개된 경로 중 원하는 방향의 전투 노드로 진입한다.
5. 문제를 풀어 몬스터를 처치하고 노드를 클리어한다.
6. 보상을 받고 새로 열린 인접 노드를 탐험한다. HP가 0이 되면 해당 노드는 미클리어 상태로 남고, 지도 전체를 종료·아카이빙한다.
7. 새로운 난이도 결정 노드에서는 다음 구간의 난이도를 선택한다.
8. 나갈 때는 상태를 저장하고 나중에 이어 한다. 전체 전투 노드 클리어 또는 사용자의 탐험 종료 시 결과를 확정하고 아카이빙한다.

## 3. 기능과 규칙

### F1. 학습 자료 업로드 및 분석

- 완성 서비스는 복수 학습 자료 입력을 지원한다. 첫 구현은 텍스트 추출이 가능한 PDF 한 개로 시작하며, 스캔 PDF와 다른 형식은 첫 구현 범위에서 제외한다.
- 각 자료의 내용을 추출하여 해당 자료 영역의 문제와 지도 구성에 활용한다.
- 지도 생성 시 상·중·하 난이도별 문제를 모두 생성하고, 난이도 선택 결과에 따라 사용할 문제를 배정한다.
- 문제는 기본적으로 업로드된 자료에 근거해야 한다. 부족하거나 더 자세한 학습을 제공하기 위해 외부 지식으로 보충할 수 있다. 외부 지식 보충과 자료만으로 답할 수 있어야 한다는 F3의 조건 사이 적용 범위는 5절에서 재확인한다.
- 정답·해설과 함께 근거 자료, PDF 페이지 번호와 짧은 발췌를 준비한다. 문제 형식·단일 정답성·근거 일치를 확인하며, 자동 검증만으로 정확성을 보장하지 않는다.
- 필요한 전체 문제를 준비한 뒤에만 지도 입장을 허용한다. 일부 생성에 실패하면 안내와 재시도를 제공하며, 미완성 지도에서는 플레이할 수 없다.
- 자료가 부족하면 지도 크기를 줄인다. 최소 구성도 만들 수 없다면 이유를 안내하고 생성을 중단한다. 문제 수를 채우기 위한 억지 반복은 하지 않는다.
- 초기 버전은 별도 고급 설정을 제공하지 않는다. 파일 수·용량·페이지 제한, 최소 지도 구성과 추출 실패 안내는 미정이다.

### F2. 학습 맵과 자료별 영역

- 지도는 중앙 출발점에서 사방으로 확장되는 탐험 지도다. 학습 경로는 한 줄로 고정되지 않으며 열린 경로 중 탐험 방향을 선택한다.
- 업로드한 자료마다 별도의 영역을 구성한다. 같은 주제의 자료도 합치지 않고, 서로 다른 주제의 자료도 같은 지도에 포함할 수 있다.
- 각 자료 영역은 중앙에서 서로 다른 방향으로 펼쳐진다. 자료 영역끼리는 중앙을 제외하면 연결하지 않으며, 다른 영역은 중앙으로 돌아와 선택한다.
- 각 영역 안에서는 분기·합류를 허용한다. 영역 입구마다 독립적인 난이도 결정 노드를 둔다.
- 지도 크기는 자료 분량에 따라 정하되 최대 크기를 제한한다. 영역별 배분과 산정 기준·상한은 샘플 자료로 검증하여 정한다.
- 실제 이용 중 미발견 영역의 노드와 연결은 숨긴다. 전체 구조를 보여주는 발표 개념도와 실제 공개 범위를 구분하며 공개 규칙은 F5를 따른다.

### F3. 난이도 선택

- 중앙 → 자료 영역 입구의 난이도 결정 노드 → 해당 영역의 전투 순서다. 각 영역의 첫 난이도를 독립적으로 선택한다. 첫 구현에서도 시작 노드 다음에 난이도를 선택하고 전투에 진입한다.
- 난이도는 상·중·하 세 단계다.
- 이후 진입하는 전투 노드에서는 선택한 난이도에 맞는 문제를 제공한다.
- 탐험 중 새로운 난이도 결정 노드를 만나면 난이도를 다시 설정할 수 있다.
- 난이도 결정 노드에서 선택하면 다음 난이도 결정 노드 전까지의 모든 자식 노드가 해당 난이도로 고정된다.
- 한 번 선택한 구간의 난이도는 변경할 수 없다. 다음 난이도 결정 노드에서는 다음 구간의 난이도를 선택한다.
- 경로의 합류는 같은 자료 영역 안에서만 허용한다. 서로 다른 난이도 구간이 합류할 때는 난이도 결정 노드를 거쳐 다음 구간의 난이도를 정한다.
- 난이도는 사고 수준으로 구분한다. 하: 개념 확인 / 중: 비교·관계 이해 / 상: 사례 적용·추론이며, 모든 난이도는 업로드한 자료만으로 답할 수 있어야 한다.
- 초기 버전은 선택한 난이도에 따라 몬스터 수나 공격력을 바꾸지 않는다. 추가 난이도 결정 노드의 배치 간격은 미정이다.

### F4. 문제 풀이 기반 턴제 전투

- 초기 버전은 전투 노드마다 몬스터가 1~3개체 등장한다.
- 몬스터마다 문제 하나를 제시하며, 초기 버전은 정답 하나를 고르는 객관식만 지원한다. 선택한 보기가 해당 문제의 정답인지 판정한다.
- 사용자가 정답을 제출하면 해당 몬스터를 처치한다.
- 답안 제출 후 살아남은 몬스터들이 공격하여 HP가 감소한다. 정답으로 몬스터를 처치해도 나머지 몬스터의 공격을 받는다. 예를 들어 3개체 중 하나를 처치하면 나머지 2개체가 공격한다.
- 위 반격 규칙은 현재 팀 합의에 가까운 작업 기준이다. 기존의 '오답일 때만 반격' 방식은 팀 재논의 후보로 남긴다.
- 오답을 내면 오답 여부만 알리고 해당 몬스터의 같은 문제에 다시 답한다. 정답·해설과 근거 PDF 페이지 번호·짧은 발췌는 문제를 맞힌 뒤 공개한다. 살아 있는 몬스터 중 공격 대상을 자유롭게 선택하며, 오답 후에도 다른 몬스터로 변경할 수 있다.
- HP는 지도 전체에서 유지하며, 노드 진입 시 자동으로 최대 HP로 초기화하지 않는다.
- 초기 버전의 회복 수단은 회복 소모품으로 한정한다. 회복 노드는 초기 범위에서 제외하며, 회복량과 지급량은 미정이다.
- 노드 클리어 시 자동 회복을 추가하는 안은 팀 재논의 후보이며, 현재 기준에는 포함하지 않는다. 회복 선택이 사실상 강제될 우려가 있어 클리어 보상에 회복 선택지를 항상 보장하는 안은 채택하지 않는다.
- HP가 0이 되면 해당 노드는 클리어 실패로 처리하고, 지도 전체를 종료·아카이빙한다. 이 종료 정책은 현재 팀 합의이며 재논의 가능하다.
- 정답 처치·PASS·문제 오류 제외로 남은 몬스터가 없어지면 노드를 클리어하고 보상을 지급한 뒤 전투를 종료한다.
- 아이템 사용은 턴을 소모하지 않으며 적의 반격을 발생시키지 않는다. 문제에 답했을 때만 반격한다.
- PASS는 해당 문제를 건너뛰고 그 몬스터를 전투에서 제거한다. 정답을 맞힌 처치와는 구분한다. PASS로 마지막 적을 제거해도 클리어·보상·지도 진행도를 정상 처리한다. 해당 문제는 정답이 아닌 건너뜀으로 기록하고, PASS 직후 정답·해설·근거 PDF 페이지와 발췌를 표시한다. 초기 버전에는 단일 게임 점수로 환산하지 않는다.
- 사용자가 문제에 오류가 있다고 판단하면 해당 문제를 제외하여 몬스터를 전투에서 제거할 수 있다. 정답·일반 PASS와 구분하여 오류 제외로 기록하며, 제외만으로 적이 없어져도 클리어를 허용한다. 오류 제외 전 받은 피해는 복구하지 않고, 이후 전투에서만 해당 적을 제외한다. 초기 결과 화면에서는 오류 제외 항목으로 구분하며, 정답률·게임 점수 공식은 보류한다.
- 클리어 보상은 제시된 소모품 중 하나를 선택한다. 초기 보상은 회복·PASS를 활용하며, 매번 회복 선택지를 보장하지 않는다.
- 인벤토리는 지도마다 독립적이다. 아이템은 획득한 지도 안에서만 사용하고, 나갔다 이어 할 때 유지한다. 아카이브 재플레이 시 인벤토리 처리는 미정이다.
- 초기 HP, 몬스터별 피해량, 회복 소모품의 회복량, 보상 선택지 수·구성·지급량은 미정이다.

### F5. 탐험 및 노드 개방

- 미발견 영역은 바로 인접한 노드까지만 공개하며, 그 너머는 선행 노드를 클리어하기 전까지 숨긴다.
- 한 번 발견한 노드는 다른 위치로 이동해도 계속 표시한다.
- 노드를 클리어하면 그 노드에 인접한 새 노드가 열린다.
- 전투 실패는 클리어로 처리하지 않으며, 클리어 보상이나 후속 노드 개방을 발생시키지 않는다.
- 합류 지점은 연결된 선행 경로 중 하나만 클리어해도 진입할 수 있다. 다른 선행 경로의 클리어를 요구하지 않는다.
- 전체 완료를 위해 선택하지 않았던 가지도 돌아가서 탐험할 수 있어야 한다. 클리어한 노드는 재전투 없이 통과하며 추가 보상을 지급하지 않는다. 통과 가능한 경로로 연결된 방문 노드를 클릭하면 바로 이동할 수 있다. 미클리어 전투 노드를 건너뛰어 이동할 수는 없다.

### F6. 학습 진행도 표시

- 맵 화면 상단에 학습 진행도를 표시한다.
- 노드 클리어 결과를 진행도에 반영하여 맵 완성까지의 진척을 보여준다.
- 진행도는 `클리어한 전투 노드 수 / 지도 전체 전투 노드 수 × 100`으로 계산한다. 미발견 전투 노드도 분모에 포함하고, 비전투 노드는 제외한다.
- 전체 전투 노드를 모두 클리어하면 100% 완료다. 선택하지 않았던 가지도 완료해야 하며, 선택하지 않은 난이도의 문제까지 모두 풀 필요는 없다.

### F7. 지도 종료 및 아카이빙

- HP가 0이 되면 진행 중인 지도를 종료하고 아카이빙한다.
- 전체 전투 노드 클리어 또는 사용자의 '탐험 종료' 선택 시에도 현재 결과를 확정하고 아카이빙한다. 초기 결과 화면은 지도 진행도와 문제별 학습 결과를 표시하며, 단일 게임 점수 공식은 팀 논의로 보류한다.
- 문제별 결과는 첫 시도 정답 / 재시도 후 정답 / PASS / 오류 제외 / 미해결로 구분한다. 선택하지 않은 난이도의 문제까지 풀도록 요구하지 않는다.
- '나가기'는 탐험 종료와 구분한다. HP·인벤토리·진행 상태를 저장하며, 나중에 해당 지도를 이어 할 수 있다. 전투 중에는 답안 판정과 적 반격을 한 턴으로 묶어 저장하고, 마지막 완료 턴 다음부터 이어 한다. HP·처치한 적·사용한 아이템 상태를 유지한다. 아이템 사용은 별도 턴을 만들지 않는다. 사용 결과와 소모된 수량도 저장하여 나가기 후 되돌아가지 않도록 한다.
- 아카이빙된 지도는 별도 메뉴에서 플레이할 수 있다. 처음부터 재시작하는지, 이어서 진행하는지, 복습 전용인지 등 플레이 방식은 미정이다.
- 아카이빙 후 플레이에서 HP·문제·난이도 선택·인벤토리·기존 기록을 어떻게 처리할지는 팀과 추가 논의한다.

### F8. 실행 환경 및 지도 목록

- 초기 버전은 사용자 PC에서 실행하는 로컬 웹 서비스이며, 같은 PC에서 지도를 저장하고 플레이한다.
- 메인 화면에서 지도를 만들거나 기존 진행 중 지도를 선택해 이어 한다. 아카이빙된 지도는 별도 메뉴에서 확인한다.
- AI 생성에는 외부 API를 사용할 수 있다. 로컬 실행이 오프라인 AI 생성을 뜻하지는 않는다.
- 구체적인 저장 방식과 AI 제공자·설정 방식은 미정이며, 다른 기기 간 기록 동기화는 초기 범위에 포함하지 않는다.

## 4. 개발 순서

PDF 한 개의 첫 전투를 먼저 검증한 뒤 탐험·보상 반복, 저장·이어하기, 복수 자료·자료별 영역으로 확장한다. [개발 계획](minimum-loop-issues.md)에서 단계와 연결 책임을 확인한다. 작업별 진행과 완료 근거는 Linear와 PR에 기록하며, 협업 기준은 [CONTRIBUTING](../CONTRIBUTING.md)을 따른다.

## 5. 팀 재논의 사항

변경 합의 전까지 채택된 규칙을 유지한다. 미정이거나 조건이 충돌하는 항목은 관련 구현 전에 적용 범위를 정한다.

| 항목 | 현재 기준 | 팀에서 논의할 내용 |
| --- | --- | --- |
| 반격 조건 | 정답 여부와 관계없이 답안 제출 후 생존한 적 모두 반격 | 오답일 때만 반격하는 방식으로 변경할지 |
| 자동 회복 | 회복 소모품만 사용. 클리어 자동 회복과 회복 노드는 초기 제외 | 클리어 시 일정 HP 자동 회복을 추가할지 |
| HP 0 처리 | 해당 지도 전체 종료·아카이빙 | 학습 중단 부담을 고려해 현재 종료 정책을 유지할지 |
| 아카이브 재플레이 | 별도 메뉴에서 플레이한다는 방향만 확정 | 재시작·이어하기·복습 중 방식, HP·문제·난이도·인벤토리 초기화 여부, 원래 기록 보존 방식 |
| 점수·정답률 | 초기에는 진행도와 문제별 결과만 표시 | 단일 점수나 정답률 도입 여부 및 재시도·PASS·오류 제외 집계 방식 |
| 외부 지식 보충 | F1은 보충을 허용하고 F3은 자료만으로 답할 수 있어야 한다고 규정 | 보충의 허용 범위와 출처 표시. 첫 흐름은 원자료 근거로 확인 가능한 문제부터 검증 |

## 6. 샘플 자료와 플레이로 조정할 수치

아래 값은 임의로 확정하지 않는다. 해당 Slice 착수 때 임시값을 정하고 샘플 PDF와 실제 플레이로 검증한다. **노드당 적 1~3마리, 난이도 상·중·하, 보상 중 하나 선택은 이미 확정된 규칙**이다.

| 항목 | 정할 값 | 검증 관점 |
| --- | --- | --- |
| 입력 제한 | 파일 수·PDF 최대 용량·페이지 수 | 추출 성공률, 생성 시간·비용 |
| 지도 크기 | 최소·최대 전투 노드 수, 자료량별 산정 기준, 자료 영역별 배분 | 자료가 짧을 때 억지 문제 생성 방지, 충분한 범위 학습 |
| 난이도 구간 | 추가 난이도 결정 노드 간격 | 같은 난이도를 유지하는 학습량과 변경 기회 |
| 전투 체력 | 초기·최대 HP, 몬스터별 피해량 | 정답만 맞혀도 받는 누적 피해와 지도 완주 가능성 |
| 소모품 | 회복량, 시작 시 지급 여부·수량, 보상 지급량 | 회복 선택지가 보장되지 않는 조건에서 생존 가능성 |
| 보상 구성 | 선택지 수, 회복·PASS 구성과 출현 빈도 | 회복 강제 선택이나 PASS 위주의 진행에 치우치는지 |

## 7. 구현 시 정할 세부 사항

추가 기능을 늘리기보다 해당 흐름을 구현할 때 필요한 범위에서 결정한다.

- **업로드·생성:** 추출·생성 실패 안내와 복수 자료 중 일부 실패 처리, 재시도 범위와 횟수, 생성 중 상태 표시. 전체 문제 준비 전 입장 금지 원칙은 유지한다.
- **AI·저장:** AI 제공자·설정 방식, 같은 PC 내 저장 방식과 저장 실패 처리.
- **맵:** 구간 내부 연결 생성 규칙과 난이도 결정 노드의 화면 표시 이름. 자료 영역 간 연결 금지와 합류 진입 조건은 유지한다.
- **학습 결과:** 미방문·난이도 미선택 영역의 표시 범위, 이전 오답 이력과 최종 결과의 저장 방식. 초기에는 단일 점수로 환산하지 않는다.
- **품질 확인:** 문제의 단일 정답성, PDF 근거의 정확성, 난이도별 사고 수준, 저장 후 이어하기의 일관성을 검증한다.

## 8. 초기 범위 제외 및 추후 확장

- 복수 자료·자료별 영역은 완성 목표이며 첫 구현 이후 확장한다.
- 스캔 PDF 인식, PDF 외 문서 형식, 자료 영역의 수동 분할·병합은 현재 필수 범위에 포함하지 않는다.
- 고급 설정·커스터마이징: 설정 항목·허용 범위·변경 시 동작을 명세한 뒤 확장한다.
- **우선도 기능 — 추후 확장 후보:** 자료 업로드 시 특정 학습 범위에 가중치를 설정한다. 범위 선택 방식과 가중치가 출제 빈도·문제 수·난이도 중 무엇에 영향을 주는지는 추후 명세한다.
- **틀린 문제 기습 — 추후 확장 후보:** 이전에 틀린 문제를 이후 학습 중 다시 출제하는 방향을 검토한다. 재출제 시점·빈도, 같은 문제 또는 변형 문제 여부, 전투·보상·진행도에 미치는 영향은 추후 명세한다.
- 위 두 후보는 초기 구현 범위에 포함하지 않으며, 현재 확정한 문제 일괄 생성·난이도 구간 고정·전투 내 오답 재시도 등 기존 규칙을 변경하지 않는다.
- 회복 노드와 회복·PASS 외 아이템, 성장 시스템, 별도 오답 노트·복습 기능은 초기 필수 범위에 포함하지 않는다.
- 로그인·다른 기기 간 동기화·랭킹·멀티플레이는 초기 필수 범위에 포함하지 않는다.
- 아카이브 재플레이는 삭제한 기능이 아니라, 5절의 팀 합의를 기다리는 후속 Slice다.
